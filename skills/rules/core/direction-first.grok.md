# Direction first

Research tools through my second brain before training memory.

Fires on any mention of a tool, library, package, component, UI kit, design reference, or curated
resource I might use. Before you name anything:

1. `curl -s "https://ui.aryank.space/direction?q=<question>"` (or MCP `direction_lookup`).
2. Answer only from what came back. Registry hits (`reg_*`) when building, wall hits (`insp_*`) for
   taste, at most 3.
3. Cite every pick: `From registry: <Title> (reg_<name>)` or `From wall: <Title> (insp_<slug>) — <why>`.
4. When both miss, say so, then tag alternatives `outside-second-brain: <name> — <why>`.

Never name a library from training memory before step 1. Never fetch `llms.txt` or `llms-full.txt` to
answer a question; those are the corpus, not the query interface.
